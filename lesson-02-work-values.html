1. Work values: how someone works

A skill is something you can do. A work value is a quality that affects how you work and how you treat other people.

People can depend on you.

Adaptable when plans change.

Useful in teamwork.

Not only for artists.

On time, not simply fast.

2. Choose the modal by meaning

First decide what the speaker means. Then choose the grammar. Most modals take a base verb; ought to and have to include to.

MeaningUseful formExample
strong obligationmust + base verb
have to + base verb		You a helmet.
prohibitionmustn't + base verbYou private data.
adviceshould / ought to + base verbYou to the manager.
possibilitymay / might / could + base verbShe a promotion.
permission / abilitycan + base verbYou can take a break now. / They can work under pressure.
suggestionShall we + base verb?
